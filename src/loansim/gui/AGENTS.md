# GUI instructions

This directory contains only the Phase 0 startup shell until Phase 2 is authorized. Keep it presentation-only; financial formulas and persistence belong to future validated modules. Do not add scenario inputs, comparison, optimization, provider, or export flows in Phase 0. Keep the startup window responsive and avoid blocking network or expensive work in the UI thread. Validate any later inputs explicitly, report errors accessibly, preserve user data, and run GUI smoke tests after every GUI change. The root `AGENTS.md` and `harness/status.md` control authorization.
